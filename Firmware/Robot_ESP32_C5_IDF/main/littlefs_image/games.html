Object detection model

Object detection and Scavenger Hunt run YOLOv8n in this browser. The model (~7 MB) and the ONNX runtime (~11 MB) are downloaded from jsDelivr the first time, so the device needs internet access once. Both are cached afterwards.

The standard model is Firmware/Robot_ESP32_C5_IDF/cdn/yolov8n-lynxp.onnx in the LynXP repository, built with tools/export_yolo_model.py. Another YOLOv8-format model can be tried by entering its URL (it must allow cross-origin downloads, as jsDelivr and raw.githubusercontent.com do).

If nothing happens on a phone: some browsers only let https pages use gamepads, and the robot serves plain http. In Chrome, open chrome://flags/#unsafely-treat-insecure-origin-as-secure, enable it, enter http://<robot address> and relaunch Chrome.
