Object detection model

Object detection and Scavenger Hunt run YOLOv8n in this browser. The model (~7 MB) is stored on the robot; the ONNX runtime (~11 MB) is downloaded from jsDelivr the first time, so the device needs internet access once. Both are cached afterwards.

Build the model with tools/export_yolo_model.py in the robot firmware folder. Installing pauses the robot for about a minute while it writes to flash.
