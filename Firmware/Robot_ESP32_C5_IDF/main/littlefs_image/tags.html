Block tags (AprilTag)

Print at 100% scale ("actual size", no "fit to page"), then check one black square with a ruler. Cut along the dashed lines and glue a tag on each face, centered: the same id on all of a block's faces (or different ones), but each id on one block only. Matte paper is best -- glare hides tags. Sizes must match the game's settings (Games & apps: Knight on Blocks).
